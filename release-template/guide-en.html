EasyScript for Premiere Pro

Silence cut · transcription · speaker labeling · subtitles · translation · voice / music separation · beat markers — directly on your timeline. Installation & User Guide — version 2.3

1. Requirements

  • Adobe Premiere Pro 2022 or later (macOS 13+ or Windows 10/11).
  • About 9 GB free: backend ~3 GB; models downloaded the first time each feature is used: Turbo transcription ~1.6 GB, voice / music separation ~0.9 GB, NLLB translation ~3 GB.
  • EasyScript runs on the GPU first: Apple Silicon Macs (Metal) are fastest; on Windows an NVIDIA GPU speeds up transcription and any GPU (DirectML) speeds up speakers and separation. Computers without a GPU work too, just slower.
  • Internet is needed the first time each feature is used, to download its model. After that everything runs offline on your computer.

2. Installation

The install folder contains the panel EasyScript-Premiere.zxp (the same file for Mac and Windows), a backend/ folder, the automatic installers and this guide. Quit Premiere completely before installing.

Option 1 — Automatic install (recommended)

macOS: right-click install-mac.command → Open → Open (macOS asks the first time). The script installs the panel and the backend.

Windows: double-click install-win.bat (if blocked: right-click → Run as administrator).

Option 2 — Manual install with the ZXP file

  1. Install the panel: open EasyScript-Premiere.zxp with a ZXP installer such as ZXP Installer (aescripts) or Anastasiy’s Extension Manager (both free, for Mac and Windows): drag the .zxp onto the installer window.
  2. Copy the backend: copy everything inside the backend/ folder to the path below (create the folders if needed). Nothing to build or install — the backend is ready to run.
    SystemPathAfterwards this file must exist
    macOS~/.easyscript/backend~/.easyscript/backend/EasyScript-backend
    Windows%USERPROFILE%\.easyscript\backend…\.easyscript\backend\EasyScript-backend.exe
    The .easyscript folder is hidden: on a Mac press Cmd + Shift + G in Finder and type ~/.easyscript; on Windows type %USERPROFILE%\.easyscript in File Explorer’s address bar.
  3. macOS only: open Terminal and run this so macOS lets the backend start (required for downloaded / unzipped files):
    xattr -dr com.apple.quarantine ~/.easyscript/backend
Copy the contents of backend/, not the folder into itself (wrong: .easyscript/backend/backend/…). When updating, delete the old backend folder first, then copy the new one.
Open the panel: Window → Extensions → EasyScript. The panel starts the backend automatically (the badge shows Connecting → Connected). The first use of each feature downloads its model (needs internet, takes a few minutes).

3. Workflow

The top of the panel holds the audio source and the waveform; below are 3 tabs: Cut (silences), Transcript (transcription, speakers, subtitles, translation) and Beats (beat markers).

StepWhat to do
1 SourceSelect a clip on the timeline (or set In/Out points, or use the whole sequence) and click Load audio. The waveform appears; scroll to zoom, drag to pan, click to move the playhead.
2 Separate voice / music NEWClick Separate voice / music… → Voice only (music removed — for transcription) or Music only (voice removed — for beats). The separated audio replaces the original in the waveform, playback, transcription and Beats; Original | Voice | Music switches instantly. The first run downloads a ~870 MB model.
3 Put it on the timeline NEWImport voice / music to timeline places the separated audio at its original timecode on the first audio track that is empty for that whole range (it never overwrites existing audio and skips locked tracks). If every track has audio there, the panel adds a new track. The file is saved in EasyScript Stems inside the Export folder and in the project bin EasyScript Stems.
4 Detect silenceCut tab: find silences, adjust padding / dB threshold / minimum length and preview them on the waveform.
5 CutApply cut edits the timeline directly. Cut to new sequence builds a new, cut sequence in one step (recommended for long videos; the original stays untouched).
6 TranscribeTranscript tab: choose the Model (default Turbo — accurate and fast) and Language. Vocabulary: enter names, brands and terms to recognise them better. For songs / videos with background music, separate Voice only first (or turn on Song mode) for cleaner text.
7 SpeakersSpeaker labeling — no account or token needed. A line spoken by two people is split exactly where the speaker changes. Click a speaker tag to rename, move the line to another speaker or create a new one; giving two speakers the same name merges them.
8 Voice memoryWhen you rename a speaker (e.g. "Speaker A" → "Anna"), that voice is saved. In later videos the person is recognised automatically (✓ next to the name). Manage saved voices in Settings.
9 Tag speakerCuts clips where the speaker changes, names and colours them per speaker. New sequence — exact: builds a new sequence, frame-exact, music / B-roll untouched. In place: edits the open sequence.
10 SubtitlesMake subtitle creates captions on the timeline (original + any translations). Export SRT saves a file. Line breaks follow the Segments "Display mode"; timing comes from word timestamps.
11 TranslateSegments → Translation tab: add target languages and click Translate. Choose the engine in Settings (NLLB-200 offline, Ollama, Hy-MT2 or Claude API).
12 BeatsBeats tab: detect the beat (best on Music only), choose the marker spacing (1/4 beat → 4 bars), review on the waveform, then add markers. Add to → Timeline: sequence markers. Add to → Selected clip: markers on the clip selected in the timeline (e.g. the music you just imported), moving with it; with nothing selected, on the clip of the audio loaded in the panel.

4. Settings (⚙ button)

  • Export folder: where SRT / XML files and imported voice / music files (subfolder EasyScript Stems) are saved. Keep those files while a project uses them.
  • Speakers: saved voices (delete any of them). "Speaker options" in the Transcript tab: known number of speakers, sensitivity, speed, recognise saved voices.
  • Translation: choose the engine. NLLB-200 runs offline: click Download once (~2.4 GB, then optimised for your computer); Ollama / Hy-MT2 run locally; Claude API needs an API key.

5. Troubleshooting

ProblemFix
"EasyScript" is missing from ExtensionsOption 1: run the installer again. Option 2: reinstall the .zxp with the ZXP installer. Then quit & reopen Premiere.
The badge stays OfflineThe backend isn't running. Check the backend file is at the path in section 2 (Option 2). On a Mac, run the xattr command above again. Then close and reopen the panel. The first start can take a few minutes.
First Speakers / Separate run is slowNormal: the model is downloaded and loaded the first time. Later runs are fast.
Separation is slowWithout a GPU it runs on the CPU (a few times the audio length). The progress line shows the device (e.g. GPU · Metal, GPU · DirectML, CPU).
Import to timeline added a new trackBy design: every audio track already had audio in that range (or was locked), so a track was added instead of overwriting.
"Selected clip" markers landed on the wrong clipSelect the clip to mark in the timeline before clicking Add markers. The status line names the clip that was marked.
Wrong number of speakersSet Known speakers or change Sensitivity in "Speaker options"; fix lines by hand by clicking the speaker tag.
Note: EasyScript never modifies your source files. Cuts and renames apply to timeline clips; separated voice / music are new files. You can Undo (Cmd/Ctrl + Z) at any time.
