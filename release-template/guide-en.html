EasyScript for Premiere Pro

Silence cut · transcription · speaker labeling · subtitles · translation · beat markers — directly on your timeline. Installation & User Guide — version 2.2

1. Requirements

  • Adobe Premiere Pro 2022 or later (macOS or Windows 10/11).
  • About 8 GB free: backend ~3 GB, Turbo transcription model ~1.6 GB (downloaded on first use), NLLB translation model ~3 GB (only if used).
  • Fastest on Apple Silicon Macs or Windows PCs with an NVIDIA GPU. Computers without a GPU work too (slower).
  • Internet is needed the first time to download models. After that everything runs offline on your computer.

2. Installation

The folder you received contains EasyScript-Premiere.zxp, a backend/ folder, the installers and this guide.

macOS

  1. Quit Premiere completely (Cmd + Q).
  2. Right-click install-mac.command → Open → Open (macOS asks the first time).
  3. The script enables extensions and installs the panel and backend. Then reopen Premiere.

Windows

  1. Quit Premiere.
  2. Double-click install-win.bat (if blocked: right-click → Run as administrator).
  3. When it finishes, reopen Premiere.
Open the panel: Window → Extensions → EasyScript. The panel starts the backend automatically (top corner shows Connecting → Connected). The first transcription / translation downloads its model (needs internet, takes a few minutes).

3. Workflow

The panel has 3 tabs: Cut (silences), Transcript (transcription, speakers, subtitles, translation) and Beats (music beat markers).

StepAction
1 SourceSelect a clip on the timeline (or set In/Out, or use the entire timeline) and click Load audio. Scroll to zoom the waveform, drag to pan, click to move the playhead.
2 Detect silenceCut tab: find silences, tune padding / dB threshold / minimum length and preview them on the waveform.
3 CutApply cut edits the timeline directly. Cut to new sequence builds a new, already-cut sequence in one step (recommended for long videos; the original stays untouched).
4 TranscribeTranscript tab: pick the Model (default Turbo — accurate and fast) and Language. Vocabulary: type names, brands or terms so they are recognised correctly.
5 SpeakersIdentify who is speaking — no account or token needed. Lines where two people talk are split at the right word. Click a speaker tag to rename, move the line to another speaker or create a new one; giving two speakers the same name merges them.
6 VoicesWhen you rename a speaker (e.g. "Speaker A" → "Lan") their voice is saved; in later videos that person is recognised automatically (✓ next to the name). Manage saved voices in Settings.
7 Tag speakerCuts clips where the speaker changes and names / colours each clip per speaker. New sequence — exact: builds a new sequence, frame-exact, music / B-roll untouched. In place: edits the open sequence.
8 SubtitlesMake subtitle creates captions on the timeline (original + translations). Export SRT saves a file. Line breaks follow the Segments "Display mode", timed by word.
9 TranslateSegments → Translation tab: add target languages and click Translate. Choose the translator in Settings (NLLB-200 offline, Ollama, Hy-MT2 or Claude API).
10 BeatsBeats tab: detect the beat, choose marker spacing (1/4 beat → 4 bars), preview on the waveform, then add markers to the clip or the timeline.

4. Settings (⚙ button)

  • Export folder: where SRT / XML files are saved.
  • Speakers: saved voices (delete any of them). "Speaker options" in the Transcript tab: known number of speakers, sensitivity, speed, recognise saved voices.
  • Translation: choose the translator. NLLB-200 runs offline: click Download once (~2.4 GB, then it optimises itself for your computer); Ollama / Hy-MT2 run locally; Claude API needs an API key.

5. Troubleshooting

SymptomFix
"EasyScript" missing from ExtensionsRun the installer again, then quit & reopen Premiere.
Panel stays OfflineThe backend isn't running. Close and reopen the panel (it starts the backend). The first start can take a few minutes.
First Speakers run is slowNormal: the model loads the first time (~10–20 s). Later runs are fast.
First transcription / translation is slowThe model is downloading (needs internet). Only once.
Wrong number of speakersSet Known speakers or change Sensitivity in "Speaker options"; fix lines by clicking the speaker tag.
Note: EasyScript never modifies your source files. All cuts/renames apply to clips on the timeline — you can Undo (Cmd/Ctrl + Z) at any time.
