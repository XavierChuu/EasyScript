### Short description (for the top of the page)

### Full description

**Edit talking videos in a fraction of the time.**
Podcasts, interviews, courses, vlogs, sermons, webinars — if it's people talking, EasyScript does the boring part for you.

**✦ What it does**

- **Auto Silence Cut** — Detects every pause and removes the dead air in one click. Picture-perfect ripple edit that keeps audio and video perfectly in sync. Works on long files too.
- **AI Transcription** — Accurate speech-to-text powered by Whisper, with support for many languages. Runs on your own machine.
- **Speaker Detection & Tagging** — Automatically figures out who's talking, splits the timeline by speaker, and names each clip — even when two people talk back-to-back with no pause.
- **Translation & Bilingual Subtitles** — Built-in offline translation (NLLB-200) plus optional Ollama / Claude. Generate dual-language subtitles (e.g. original + English) in one pass.
- **Subtitle Generation** — Export clean SRT and import straight into your Premiere project, with before/after-cut timing and flexible display modes.
- **Waveform Editor** — Zoomable waveform tinted by speaker, so you can see your edit at a glance.

**✦ Why creators love it**

- 🔒 **Private & offline** — Your media never leaves your computer (cloud AI is optional, off by default).
- 💸 **One-time purchase** — No subscriptions, no per-minute fees, no credits.
- ⚡ **Fast** — Built directly on Premiere's native editing engine for instant, link-preserving cuts.
- 🎬 **Lives inside Premiere** — A real panel under Window ▸ Extensions, not a separate app you export to.

**✦ What's included**
- EasyScript panel for Premiere Pro (signed .zxp)
- Bundled local AI backend (no Python setup needed)
- One-click installer
- User Guide (English + Vietnamese, PDF)

**✦ System requirements**
- Adobe Premiere Pro 2022 or newer (v22.0 – 25.x / 2026)
- **macOS — Apple Silicon (M1 / M2 / M3 / M4)**
- ~3 GB free disk space
- First run may download additional AI models. Speaker detection uses a free Hugging Face token (instructions included).
- *Windows version sold separately / available on request.*

**✦ Quick start**
1. Unzip and run the installer.
2. Restart Premiere Pro.
3. Open Window ▸ Extensions ▸ EasyScript.
4. Select a clip → Load Audio → Detect Silence → Apply Cut. Done.

**✦ FAQ**
- **Do I need to install Python or anything technical?** No. The AI engine is bundled and starts automatically.
- **Does it upload my video anywhere?** No. Everything runs locally unless you opt into a cloud provider.
- **Which languages?** Whisper supports 90+ languages for transcription; translation covers 200 languages via NLLB.
- **Will it work on Intel Macs / Windows?** This package is for Apple Silicon Macs. Ask about Windows/Intel builds.
- **Updates?** Free updates within this major version.
